# bashlib-create

A template generator used by bashlib tool chain to create a variety of different template files. 
made to be used as a CLI tool.


## Table of Contents

- [What You Get](#what-you-get)
- [Quick Start](#quick-start)
- [Installation](#installation)
- [Basic Usage](#usage)
- [Contributing](#contributing)
- [License](#license)

## What You Get

- `create file`: Generate documents
- `create script`: Generate bash scripts
- `create project`: Generate a bash project template
- `lib/bashlib-create`: source this file for access to the base libraries

## Quick Start

Clone the repository and install the tool:

```bash
git clone "https://github.com/JMinyard1335/bashlib-create"
cd bashlib-create
chmod +x bashlib-create
./bashlib-create --help
```

## Installation

This repo keeps install details in a separate file.

- See [INSTALL.md](docs/INSTALL.md) in `docs` for local, user, and system-wide install options.
- If you use `bashlib-installer` use the code below.

``` bash
git clone "https://github.com/JMinyard1335/bashlib-create"
installer install bashlib-create
```

## Usage

Here are each of the help commands for this tool. Use those to pull up the docs on how to use them.
Or for even more info go to the [API](docs/API.md) docs.

```bash
create --help
create project --help
create file --help
create script --help
```
